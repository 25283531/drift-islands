# 漂流岛屿 · M3 实现说明

版本：M3（团队、冲突、成长与后台）
对应设计：`docs/设计说明.md` v1.4 §3、§4.1、§4.2、§4.3

## 1. 范围

M3 覆盖任务书 3.1–3.11：

| 任务 | 落地 |
|---|---|
| 3.1 团队系统 | 建队、邀请、加入、退出、解散、称号；队员可上队长船；同船人数进入移动油耗 |
| 3.2 PvP 与夺岛 | 面对面决斗（多回合结算、败者掉落全部随身物）；基地逐级摧毁；防御清零后连续驻留 1 世界小时完成占领 |
| 3.3 物理交易 | 面对面发起/接受/拒绝；同岛或 1 海里内；藏匿点放置与拾取（任意第三方在 0.2 海里内可取） |
| 3.4 技能领悟 | 固定等级 1/3/5/7 从资质预置池领悟；参考最近 2 世界日经历，模型优先、规则兜底 |
| 3.5 怪物智慧分级 | 1–3 级本能、4 级集火、5 级交谈、7 级大模型决策（陷阱/谈判/交易）；失败回落规则 |
| 3.6 7 级怪物交易 | 用晶核换随身物资；接受后晶核入手、物资归怪物 |
| 3.7 GM 后台 | 总览、世界事件增改查、模型池读写、审核记录查询与人工复核（`x-admin-token`） |
| 3.8 疲劳与猝死 | 日在线 8 小时后每小时 +10 疲劳；连续疲劳第 3 日起 30%+25%/日；离线每世界时恢复 25% |
| 3.9 新玩家保护期 | 建角可选保护等级；保护期内不遭遇高 2 级以上怪物；达到等级自动失效；进高等级岛仍提示 |
| 3.10 模型池 | `model_pool` 表启动播种（大小模型/优先级/启用）；同优先级随机、失败冷却 60 秒；GM 可调 |
| 3.11 联调部署 | 服务器重建、健康检查、线上脚本验收 |

## 3. 关键规则

### 3.1 团队

- 队长建队（2–12 字），邀请按角色名；被邀请人 `team_join` 加入。
- 退出：队长退出自动移交给最早加入的成员；最后一人退出即解散。
- 称号：`【队名】角色名`，队伍维度开关，默认开。
- 上船：同岛或 0.5 海里内可上队长船；下船回到自己的船。
- 油耗：`基础油耗 × min(8, 同船人数)`；漂流不计。

### 3.2 PvP 与夺岛

- 决斗：同岛或 1 海里内，双方按 `6 + 等级×5 + 船火力/防御` 结算，最多 6 回合。
  败者 `hp=0`、`status=dead`，全部随身物落到原地藏匿点。
- 基地：每次攻击降低 1 级防御（防御值 `10 + 12×等级`），防御归零才可占领。
- 占领：需在岛上，记录 `buildings.capture`（角色、起始世界日/分钟）；
  满 60 世界分钟，若原岛主不在岛上，则转移 `owner_character_id`；原岛主在岛上则防守成功。
- 进度按世界时间惰性结算（查询/操作时推进），不依赖常驻定时器。

### 3.3 交易与藏匿点

- 交易需当面（同岛或 1 海里），5 分钟有效；接受时二次校验双方物品仍在原主手中。
- 藏匿点记录 `dead_drops`，物品 `owner_type=ground`；0.2 海里内可取，先到先得。

### 3.4 技能

- 领悟等级：1/3/5/7，每个资质一条池（体/法/光/暗/元素/武）。
- 选择：取最近 2 世界日 `experience_logs`，模型从候选里挑一个；模型失败或候选唯一时按关键词命中规则挑选。
- 升级事件由 `CrystalsService` 发出 `character.levelup`，技能服务监听后写入 `skills`。

### 3.5 / 3.6 怪物

- 规则层 `monsterActions(level, hpRatio)` 决定可用行为集合。
- 7 级怪物可用大模型在集合内选择；模型不可用回落规则（低血逃跑、概率设陷阱/交谈/集火）。
- 交易：7 级怪物用 1 枚 7 级晶核换最多 2 件随身物；5 分钟有效。

### 3.7 GM

- 所有 `/api/v1/admin/*` 需 `x-admin-token`（默认 `drift-admin-2026`，生产由 `.env` 覆盖）。
- 接口：`GET overview`、`GET/POST/PATCH world-events`、`GET/PUT model-pool`、`GET moderation`、`POST moderation/:id/review`。

### 3.8 疲劳

- `touch()` 在心跳/行动时累计在线秒数；跨世界日重置当日时长并结算连续疲劳日。
- 疲劳 ≥60 视为疲劳日；连续第 3 日起按概率猝死，死亡掉落全部随身物并重置疲劳。
- `recover()` 供离线恢复调用（每世界时 25%）。

### 3.9 保护期

- 建角可传 `protection_level`，上限 10（也可后续 `protection_set`）。
- 进岛时过滤高于自身 2 级的怪物，并提示“有几只没有惊动你”。
- 等级达到保护等级后 `protection_status` 自动置为失效。

## 5. 已知限制

1. PvP 采用即时多回合结算，未接入 15 秒回合制战斗房间；组队多人同场 PvP 暂未开放。
2. 夺岛只转移归属，不迁移基地建筑等级；占领期间没有全服广播。
3. 怪物派系仅保留 `faction_id` 字段，结盟/宣战事件尚未驱动行为。
4. 模型池的优先级与启用状态已持久化并可被 GM 修改；运行时路由仍以 `.env` 模型列表为准，池配置暂未反向注入网关。
5. 技能目前只提供数值外的描述与记录，尚未接入战斗被动计算。
6. 疲劳按心跳/行动采样，离线恢复需要调用 `recover()`（M4 接入登录结算）。
