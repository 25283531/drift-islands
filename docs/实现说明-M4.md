## 2. 岛屿评分（4.1）

`islandScore()` 满分 100，四项加权：

| 维度 | 权重 | 计算 |
| --- | --- | --- |
| 访问量 | 35 | `min(1, visit_count / 50)` |
| 玩家评价 | 25 | 1 星=0、5 星=1；无评价按 0.5 中性 |
| 资源消耗 | 25 | `min(1, resources_taken / 100)` |
| 新鲜度 | 15 | `max(0, 1 - 距上次访问世界日 / 30)` |

接口：

- `POST /api/v1/islands/:id/rate` `{ score: 1-5, comment? }`：每人每岛一条，重复提交即修改。
- `GET /api/v1/islands/:id/score`：返回访问量、评价数、均分、资源消耗、分数。
- `GET /api/v1/rankings/islands?limit=10`：按分数排序的榜单。

注：`/api/v1/islands/top` 会被现有 `islands/:id` 路由截获，所以榜单放在 `rankings/islands`。

## 3. 创作者激励（4.2）

- 分档：评分 ≥85 发 300，≥70 发 150，≥60 发 60，其余不发。
- 每次结算写入 `creator_rewards` 台账：岛屿、创作者、周期世界日、评分、金额、原因、结算人、状态。
- `(island_id, period_day)` 唯一：同一世界日重复结算不会重复发放。
- 后台接口：
  - `POST /api/v1/admin/rewards/settle` `{ period_day? }`（默认当前世界日）
  - `GET /api/v1/admin/rewards`
- 玩家接口：`GET /api/v1/me/rewards` 返回本人累计激励。
- 说明：当前激励计量单位是「潮汐币」记账值，先保证可审计；消耗场景等商业化结论（4.5）后再接。

## 4. 内容治理（4.3）

闭环：玩家举报 → 后台待办 → 人工处置 → 梯度执行。

- `POST /api/v1/reports` `{ target_type, target_id, category, detail? }`
  - `target_type`：`chat_message` / `island` / `character`
  - `category`：`redline` / `harassment` / `cheat` / `bad_island` / `other`
  - 同一举报人对同一目标只保留一条待处理记录。
- 后台：
  - `GET /api/v1/admin/reports?status=pending`
  - `POST /api/v1/admin/reports/:id/resolve` `{ action: dismiss|warn|mute|ban }`
- 处置落到被举报账号：`warn` 记一条人工审核记录；`mute` 禁言 1 世界日（8 现实小时）；`ban` 封禁。
- 处置结果写回举报记录（`status`、`action`、`handled_by`、`handled_at`），可在后台复查。

## 5. 商业化方案草案（4.4，待确认）

原则：只卖外观与便利，不卖战力、不卖资源、不卖抽卡。

| 付费点 | 内容 | 是否影响平衡 |
| --- | --- | --- |
| 船体外观 | 涂装、灯色、尾迹 | 不影响 |
| 岛屿装饰 | 灯塔样式、码头摆件（岛主可买，访客可见） | 不影响 |
| 档案位 | 额外角色档案位（不含资源） | 不影响 |
| 航线记录 | 历史航线回放、截图分享 | 不影响 |
| 赞助标记 | 聊天头像框、岛主铭牌 | 不影响 |

建议：先做外观类（成本低、可验证付费意愿），不做任何数值付费；等 M5 留存数据再决定是否上线。

**4.5 结论（2026-11-14，用户确认）：商业化延后，不做付费点。**
当前版本不接支付、不做商城；`creator_rewards` 仅保留台账（审计用），不接入消费。

## 5.1 聊天指令版评分 / 榜单 / 举报

| 指令 | 行为 |
| --- | --- |
| `评分5`（或 `评分五`） | 给脚下的岛打分 1–5；不在岛上会提示先上岛 |
| `榜单` / `排行榜` | 返回评分前 5 的岛（分数 + 到访次数） |
| `举报上一条` | 举报当前频道里最近一条别人的发言，进入后台待办 |
| `反馈 内容` | 内测问题/建议写入 feedback 表 |

均走现有文字路由器，问句仍交给 AI 聊天。

## 6. 其他调整

- 交易地点规则改为：同岛可成交；两人都在海上（无线电）也可成交；一人上岛一人在海不行。线上验收不再卡“必须面对面”。
- 聊天 AI 回复去掉“必须命中游戏关键词”的限制：仍只回复提问句，但不再因为没提“岛/船/怪”就不理人。
- 英伟达模型逐个实测：`/v1/models` 列出 83 个，绝大多数 chat/completions 返回 404（Function not found），实际可用的是
  `nvidia/nemotron-3.5-bolt-e4b`、`nvidia/nemotron-3-ultra-550b-a55b`、`poolside/laguna-xs-2.1`、`nvidia/ising-calibration-1.5-31b`、
  `meta/muse-glimmer-30b`；已把其中 4 个写入模型池。
